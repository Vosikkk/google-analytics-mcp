# Security

The hosted GA4 MCP uses Google OAuth with the read-only `analytics.readonly` scope. For information about OAuth credential protection, data processing, retention, and deletion, see the [Vosik Signals Privacy Policy](https://vosiksignals.win/privacy).

## Reporting vulnerabilities

Please **do not** disclose vulnerabilities or credentials in public GitHub issues.

For private security reports, contact **vosikvos@gmail.com** with a concise description and reproduction steps. Do not include real access tokens or sensitive analytics exports unless specifically requested through a secure channel.

This documentation repository does not contain the hosted server's source code.
